# UniMed: Advanced Multimodal Medical Intelligence

UniMed is a state-of-the-art medical intelligence system designed to assist clinicians in analyzing complex medical imagery. By combining foundation models with domain-specific adaptation and similarity-based retrieval, UniMed provides accurate, explainable, and real-time diagnostic support across multiple modalities.

## 🚀 Key Features

- **Multimodal Support**: Unified analysis for Radiology (X-ray, MRI, CT), Pathology (WSI slides), and Dynamic scans (Ultrasound, Endoscopy).
- **Domain Adaptation**: Custom Residual MLP Adaptors that refine generic vision features into specialized medical descriptors.
- **Case-Based Reasoning**: FAISS-powered retrieval system that presents similar historical cases to support the current diagnosis.
- **Zero-Shot Validation**: Built-in security layer to prevent non-medical image processing.
- **Premium Dashboard**: A clean, modern interface with real-time performance metrics and printable medical reports.

## 🏗️ Architecture

The system follows a modular architecture designed for high throughput and clinical reliability:

1.  **Vision-Language Foundation**: Uses **BioMedCLIP** to create a shared embedding space between medical imagery and clinical descriptions, providing superior medical domain understanding.
2.  **Medical Adaptor Layer**: A residual multi-layer perceptron (MLP) that maps foundation embeddings into a high-fidelity medical feature space, improving sensitivity to pathological patterns.
3.  **Segmentation Network**: Integrates a **UNet** model for precise region-of-interest segmentation and visualization.
4.  **FAISS Retrieval Engine**: An L2-normalized vector database (FAISS) containing thousands of clinical prototypes for rapid similarity matching.
5.  **Inference Pipeline**:
    - **Input Validation**: Zero-shot classification to verify image modality and medical relevance.
    - **Feature Extraction**: Parallel processing of image and text queries using BioMedCLIP.
    - **Hybrid Scoring**: Diagnosis generated by combining softmax probabilities from BioMedCLIP with weighted votes from similar retrieved cases.

## 🛠️ How it Works

1.  **Upload**: The user uploads a DICOM-converted image or video stream via the dashboard.
2.  **Verify**: The `validate_image` service calculates probability scores across 8 categories (Radiology, Pathology, Animal, Object, etc.) to ensure data integrity.
3.  **Process**:
    - The **Vision Encoder** extracts global features using BioMedCLIP.
    - The **Medical Adaptor** applies residual weights to highlight abnormalities.
    - The **UNet** model generates segmentation masks for region-of-interest visualization.
4.  **Retrieve**: The system queries the **FAISS Index** to find the closest clinical matches in the dataset.
5.  **Report**: A final diagnostic summary is presented, including confidence scores, segmentation masks, similar case imagery, and performance metrics.
